# 验收标准清单（AC-01 ~ AC-10）

**阶段**：03 需求定义 · 任务 3 约定验收标准 ｜ **版本**：v1.0 ｜ **日期**：2026-11-05
**填写提纲**：REQ 编号 → 样本和前置条件 → 操作 → 预期结果与阈值 → 必须拒绝的条件 → 评审及签核人
**原则**：阈值是客户认的，不是自己定的；"一例都不能接受"的错误必须单列。

---

## 一、通用验收前提

| 项 | 内容 |
|---|---|
| 评估集 | 从 2026 Q3 的 1,268 票中分层抽样 200 票（覆盖 6 家船司、3 种币种、含 34 票已知漏收、23 票已知重复收费） |
| 对照基准 | 陈莉莉与周慧人工复核结果（双人独立核对，分歧由赵磊裁决） |

## 二、逐条验收标准

### AC-01 单票费用归集（对应 REQ-01）

| 项 | 内容 |
|---|---|
| 样本与前置 | 200 票（含 12 票多箱分批、7 票订舱号后 6 位撞号） |
| 操作 | 打开单票，比对系统归集的应收/应付行数与人工核对结果 |
| 预期结果与阈值 | 归集完整率 **≥99%**；未归集行 100% 进入"待归集"池并可见；单票加载 ≤2 秒 |
| 必须拒绝 | ① 任何费用行被静默丢弃（无任何提示）；② 撞号导致错挂而无人工确认记录 |
| 评审/签核 | 陈莉莉评审，赵磊签核 |

### AC-02 费率卡版本校验（对应 REQ-02）

| 项 | 内容 |
|---|---|
| 样本与前置 | 30 票已知漏收 + 30 票正常票（各含跨生效日 5 票） |
| 操作 | 触发校验，检查匹配到的版本号与生效区间 |
| 预期结果与阈值 | 版本匹配准确率 **≥98%**；缺费率卡的票 **100% 被阻止开票**；跨生效日按提单签发日取值正确率 100% |
| 必须拒绝 | ① 任一票在"无有效费率卡"情况下仍生成账单；② 系统擅自选用"最新版本"而不校验生效期 |
| 评审/签核 | 周慧 + 陈莉莉评审，周慧签核 |

### AC-03 供应商账单解析与比对（对应 REQ-03）

| 项 | 内容 |
|---|---|
| 样本与前置 | 8 种版式各 10 份，共 80 份账单（PDF 60 + Excel 20），含 10 份模糊扫描件 |
| 操作 | 批量解析，比对结构化字段（费用项、金额、币种、箱号） |
| 预期结果与阈值 | 关键字段（金额、箱号）准确率 **≥98%**；费用项名称归一准确率 ≥95%；版式识别率 ≥90%；单份解析 ≤10 秒 |
| 必须拒绝 | ① 解析失败却标记为"成功"并给出 0 金额；② 金额识别错误且未进入人工复核；③ 账单原件未保留索引 |
| 评审/签核 | 张伟评审，刘建国签核 |

### AC-04 漏收与重复收费识别（对应 REQ-04）

| 项 | 内容 |
|---|---|
| 样本与前置 | 200 票，其中 34 票构造/已知漏收（合计 ¥12.4 万）、23 票已知重复 |
| 操作 | 出账前检查，与人工复核结果比对 |
| 预期结果与阈值 | 漏收**金额**识别率 **≥95%**；漏收票识别率 ≥90%；误报率 **≤5%**；重复收费识别率 100%（23/23） |
| 必须拒绝 | ① 漏收被判为"正常"（漏检）；② 缺项金额 > 单票应收 5% 时不阻断开票；③ 系统自动发出补收函/账单（未人点）；④ 将异议期硬编码为 7 天导致误判 |
| 评审/签核 | 周慧 + 许安评审，周慧签核 |

### AC-05 费用追溯链（对应 REQ-05）

| 项 | 内容 |
|---|---|
| 样本与前置 | 100 笔随机费用行 + 10 笔已知断链（供应商账单未到） |
| 操作 | 展开四级链路，检查每级是否有可点击的原件 |
| 预期结果与阈值 | 链路完整率 **100%**（每笔可展开到来源单据，或明确标注"缺 XX 级"）；单笔展开 ≤2 秒；断链识别准确 10/10 |
| 必须拒绝 | ① 任一费用行"看起来完整"但实际无原件支撑（虚假完整）；② 推测性填充缺失节点；③ 追溯过程中读取到合同原文并落库 |
| 评审/签核 | 许安 + 陈莉莉评审，许安签核 |

### AC-06 差异归因（对应 REQ-06）

| 项 | 内容 |
|---|---|
| 样本与前置 | 812 条历史差异（其中已知"账单拆行"假差异 146 条） |
| 操作 | 批量归因，与人工分类比对 |
| 预期结果与阈值 | 六分类准确率 **≥85%**；"无法归类"占比 ≤10%；假差异识别率 ≥90% |
| 必须拒绝 | ① 把假差异（账单拆行）计为真实损失；② 归因结果用于处罚而无人工复核 |
| 评审/签核 | 陈莉莉评审，赵磊签核 |

### AC-07 人工控制点（对应 REQ-07）

| 项 | 内容 |
|---|---|
| 样本与前置 | 构造 20 次改单（含 6 次超阈值）、5 次补收、5 次减免 |
| 操作 | 逐次执行并尝试绕过复核 |
| 预期结果与阈值 | 超阈值操作 100% 进入双人复核；复核人=操作人 100% 被拒；审计记录 100% 完整（原因码、依据单据、时间、人） |
| 必须拒绝 | ① 任一超阈值操作未经复核即生效；② 同人自审自发；③ 无原因码的改单被接受 |
| 评审/签核 | 许安评审并签核（红线项） |

### AC-08 审计与指标（对应 REQ-08）

| 项 | 内容 |
|---|---|
| 样本与前置 | 连续 30 天运行数据 |
| 操作 | 核对日志与看板数值 |
| 预期结果与阈值 | 日志覆盖率 100%（含导出、越权尝试、降级事件）；M1–M6 指标与财务月报偏差 ≤0.2 个百分点；查询响应 ≤3 秒 |
| 必须拒绝 | ① 存在"无日志的操作路径"；② 指标口径变更未版本化 |
| 评审/签核 | 周慧签核 |

### AC-09 数据边界与权限（对应 REQ-09）

| 项 | 内容 |
|---|---|
| 样本与前置 | 4 类角色账号（结算/单证/客服/财务），20 次越权尝试 |
| 操作 | 权限矩阵逐格验证 + 导出留痕验证 + 外部调用拦截验证 |
| 预期结果与阈值 | 越权拦截率 100%；导出留痕 100%（含字段清单与接收方）；外部请求携带价格字段拦截率 **100%** |
| 必须拒绝 | ① 任一越权访问成功；② 导出无记录；③ 任何价格/毛利字段进入外部模型请求（**一例即拒绝上线**） |
| 评审/签核 | 许安签核（一票否决项） |

### AC-10 追溯包导出（对应 REQ-10）

| 项 | 内容 |
|---|---|
| 样本与前置 | 20 票（含 3 票断链、2 票多箱） |
| 操作 | 一键导出 PDF，检查内容与脱敏 |
| 预期结果与阈值 | 导出成功 100%；不含毛利/成本/其他客户信息 100%；断链标注 100%；单份生成 ≤5 秒 |
| 必须拒绝 | ① 导出内容含其他客户信息；② 断链未标注导致客户误解；③ 导出无审计记录 |
| 评审/签核 | 李文静评审，赵磊签核 |

## 三、零容忍清单（一例即不通过）

> 这五条不参与"准确率"计算，出现一次即整版拒绝，不做任何豁免。

| # | 零容忍错误 | 后果 | 对应条目 |
|---|---|---|---|
| Z-1 | 价格/毛利/成本字段进入外部模型或云端请求 | 商业秘密泄露，合规事故 | AC-09 |
| Z-2 | 客户账单中出现"无有效费率卡"的收费行 | 违规收费，客户投诉升级 | AC-02 |
| Z-3 | 同一费用行重复计入客户账单 | 重复收费，需退款并损信誉 | AC-04 |
| Z-4 | 超阈值改单/补收未经双人复核即生效 | 内控失效，审计问题 | AC-07 |
| Z-5 | 追溯链"虚假完整"（无原件却显示已追溯） | 审计与实际不符，最危险 | AC-05 |

## 四、业务目标验收（与三项基线指标挂钩）

| 指标 | 基线 | 验收阈值 | 测量方式 | 观察期 |
|---|---|---|---|---|
| 漏收率 | 1.80% | **≤0.60%** | 财务月结同口径 | 试点后 2 个完整月 |
| 结算周期（中位/天） | 11.5 | **≤6**（P90 ≤9） | CargoWare 日志 | 试点后 2 个月 |
| 账单一次通过率 | 71.3% | **≥90%** | 客服工单 | 试点后 3 个月 |
| 单笔追溯耗时 | 42 分钟 | **≤8 分钟** | 抽样 50 笔计时 | 试点后 1 个月 |
| 差异条目 | 812 条/季 | ≤240 条/季 | 差异台账 | 试点后 1 个季度 |

> 归因方法：试点前锁定 30 票对照组（同客户、同航线、同费用结构），试点后同口径对比，避免"本来就在改善"的质疑（RK-06）。
