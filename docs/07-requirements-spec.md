## 二、需求详述

### REQ-01 单票费用全景归集（P0）

| 项 | 内容 |
|---|---|
| 角色 / 场景 | 结算专员在出账前打开一票，需要看到这票的**全部**应收与应付费用行，而不是一个金额合计 |
| 任务 | 按 订单号 / 订舱号 / 提单号 / 箱号 四个键把费用行归集到单票，标注来源单据、录入人、录入时间 |
| 输入 | CargoWare 只读 API 的订单/提单/箱/费用行（15 分钟增量）；供应商账单解析结果（REQ-03） |
| 输出 | 单票费用全景视图（应收 N 行 / 应付 N 行 / 差额 / 未归集行清单） |
| 授权与排除 | 只读，不回写 CargoWare（刘建国：写入需厂家定制 18 万，超预算）；排除进口与拼箱 LCL |
| 异常处理 | ① 订舱号后 6 位撞号 → 需人工确认并记录确认人；② 一票多箱分批出运 → 按箱行展示，不合并；③ 3 个键都无法匹配 → 进"待归集"池，不得静默丢弃 |
| 证据 / 负责人 | E-010、E-018 ／ 赵磊 |
| 验收关联 | AC-01 |

### REQ-02 费率卡版本与生效期校验（P0）

| 项 | 内容 |
|---|---|
| 角色 / 场景 | 单证操作员录入费用、结算专员出账时，系统必须知道"这一笔该用哪一版费率" |
| 任务 | 每笔应收费用必须匹配到唯一「客户 + 费用项 + 生效区间」的费率卡版本；不匹配则阻断开票 |
| 输入 | 客户费率卡（结构化后入库，含客户号、费用项、币种、单价、生效起止日、版本号、审批人） |
| 输出 | 匹配结果（版本号 + 生效区间 + 匹配依据）；不匹配则输出"缺费率卡"清单 |
| 授权与排除 | 费率维护权限仅结算主管；排除自动改价、自动审批（价格属商务决策） |
| 异常处理 | ① 一票跨生效日 → 按提单签发日取版本，并在视图标注；② 客户合同未约定某费用项 → 标记"合同未覆盖"，需人工确认是否收；③ 版本冲突 → 阻断并提示两份版本差异 |
| 证据 / 负责人 | E-007、E-014 ／ 周慧 |
| 验收关联 | AC-02 |

### REQ-03 供应商账单解析与逐行比对（P0）

| 项 | 内容 |
|---|---|
| 角色 / 场景 | 单证操作员每天 32 封邮件，无法逐封阅读附加费；需要系统把账单变成结构化费用行 |
| 任务 | 解析 PDF/Excel 账单为结构化行（费用项、金额、币种、箱号、日期），与系统内应付预估逐行比对，输出差异 |
| 输入 | 船司/报关行/拖车/仓库账单（PDF 6 种版式、Excel 2 种版式，E-005） |
| 输出 | 结构化费用行 + 比对结果（一致 / 金额差 / 缺行 / 多行）+ 差异清单 |
| 授权与排除 | 解析失败不得静默通过；排除自动付款、自动生成应付凭证 |
| 异常处理 | ① 解析置信度 < 阈值 → 转人工并保留原件链接；② 版式未识别 → 进"新模板待建"队列，并告警刘建国；③ 解析失败率 > 5% → 自动降级全人工并通知（RK-03） |
| 证据 / 负责人 | E-005、E-009 ／ 刘建国 |
| 验收关联 | AC-03 |

### REQ-04 漏收与重复收费识别（P0）

| 项 | 内容 |
|---|---|
| 角色 / 场景 | 结算专员在账单发出前，需要系统告诉她"这票还少了什么、多了什么" |
| 任务 | 以"应有费用模板（按客户费率卡 + 航线条款 + 实际作业项）"对比"已录入应收"，输出缺项与重复项，并给出金额影响 |
| 输入 | 应有费用模板、已录应收费用行、供应商账单解析结果 |
| 输出 | 开票前检查报告：缺项 N 条（金额）、重复 N 条（金额）、总额偏差 |
| 授权与排除 | **只提示不阻断发送**（许安 RL-4：发送必须人点）；超阈值缺项才阻断"生成账单"；不得自动判断合同异议期 |
| 异常处理 | ① 缺项金额 > 单票应收 5% → 阻断开票，需主管复核；② 异议期条款因客户而异（7 天/15 天/无约定，E-024）→ 由合规配置，**不得硬编码 7 天**；③ 同一费用行不同来源 → 标记"疑似重复"需人确认 |
| 证据 / 负责人 | E-001、E-008、E-024 ／ 周慧 |
| 验收关联 | AC-04 |

| 任务 | 任意一笔费用可展开四级链路：来源单据（账单/邮件/委托）→ 费率条款（合同条款号/费率卡版本）→ 承担方（客户/我方）→ 凭证（账单行/发票/核销） |
