# ④ 项目原有资料（4 份）

本目录存放**项目原始资料**：不是我们写的分析，而是分析所依据的一手材料。报告里的每个数字，都应能在这里找到出处。

| 编号 | 文件 | 形式 | 在项目里的作用 | 支撑证据 |
|---|---|---|---|---|
| M-01 | `M-01_项目任务书_V2.1.docx` | Word（2 页） | 界定目标、范围、六项排除、预算与权限；报告中的"任务书 V2.1"即此件 | E-022 |
| M-02 | `M-02_结算与费用管理办法_节选.docx` | Word（2 页） | 制度层面要求：费用须有来源单据（3.2）、费率卡须登记版本与生效期（5.1）、异议期按合同（7.2）、减免权限（9）、对账时限（12） | E-023 |
| M-03 | `M-03_系统截图_费用行与费率表.png` | PNG（含 SVG 原图） | 系统现场：`fee_remark` 为自由文本、无来源单据字段；共享盘 7 个费率表版本并存 | E-007、E-018 |
| M-04 | `M-04_样例单据_三单对照.csv` | CSV（14 行） | 同一票（BK2610-0187）的船司账单、客户账单、差异台账三单对照 | E-001、E-005、E-010 |

## 这 4 份材料怎么用

| 场景 | 用法 |
|---|---|
| 说明"问题真实存在" | M-04 三单对照：船司收了 LSS/PSS/改配费，客户账单里没有，差异台账记了 3 条 |
| 说明"不是员工不用心" | M-02 第 5.1 条要求登记版本与生效期，但 M-03 右图显示 7 个版本无任何版本号——**制度有要求、系统无承载** |
| 说明"范围不会蔓延" | M-01 §3.2 六项排除（进口/拼箱/门户/总账/退税/套保+催收），与 `docs/03` §4.3 一致 |
| 说明"合规红线从哪来" | M-02 第十五条 + M-01 §7（合同不得导出、不录音、导出留痕、不得自动发送） |

## 说明：关于"还原件"

这 4 份是按 FDE 实训场景**还原**的材料，企业名、人名、单号、金额均为教学构造（见根目录 `LICENSE` 声明）。

- 如果你手上有课程/企业下发的**真实原件**：用同名文件替换即可，报告里的 E- 编号无需改动；
- 如果原件是 PDF 或扫描件：直接放进本目录，并把上表"形式"列改成实际格式；
- 不要为了"看起来像"而编造与报告数字不一致的内容——一致性比精美更重要。

## 生成方式（可复现）

| 文件 | 生成脚本 |
|---|---|
| M-01 / M-02 | 源件在 `_src/*.md`，运行 `python tools/build_source_docs.py` 转 Word |
| M-03 | `python tools/make_system_mock_svg.py` 生成 SVG，再用 resvg 渲染 PNG |
| M-04 | `M-04_样例单据_三单对照.csv`（14 行，UTF-8 BOM，Excel 可直接打开） |
