## 一、Issue #7：文档缺陷

标题：`文档：CONTRIBUTING 的本地启动命令在 Windows 下不可用，且与 README 不一致`

指出两个可验证的问题：

1. `CONTRIBUTING.md` 用 `PYTHONPATH=src uvicorn ...` 启动，而 `VAR=value 命令` 是 POSIX shell 语法，Windows 的 cmd / PowerShell 会报「不是内部或外部命令」；但该仓库 README 明确声明「Windows 原生运行同样支持」。
2. 开发环境步骤已有 `pip install -e ".[dev]"`，包已装入环境，`PYTHONPATH` 属多余，且与 README「快速开始」的写法不一致。

## 二、Pull Request #8：修复上述问题

标题：`docs(contributing): 修正本地启动命令，补充 Windows 用法`

- 分支：`yuzhouwudizhizuntianwang:docs/fix-local-dev-cmd` → `Euzohn:main`
- 改动范围：仅 `CONTRIBUTING.md` 一个代码块，**1 个文件 +9 −1**，无代码与依赖变更
- PR 正文首行写明「修复 #7」，与 Issue 互相跳转

```diff
-PYTHONPATH=src uvicorn zfundpilot.api:app --reload --port 8000
+# 已执行 pip install -e ".[dev]" 时可直接启动，无需再设置 PYTHONPATH
+uvicorn zfundpilot.api:app --reload --port 8000
```
