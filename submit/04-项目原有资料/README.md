# ④ 项目原有资料（4 份）

本目录用于存放**客户/课程提供的原始资料**，不含任何我方编写的分析内容。按白板要求共 4 份，编号如下：

| 编号 | 资料名称 | 形式 | 在项目里的作用 | 当前状态 |
|---|---|---|---|---|
| M-01 | 项目任务书 / 需求简报（Brief） | PDF / 图片 | 界定范围与排除项（本报告引用为任务书 V2.1，E-022） | ⬜ 待放入原件 |
| M-02 | 业务背景与现行制度说明 | PDF / Word | 提供公司业务、结算规则的原始表述 | ⬜ 待放入原件 |
| M-03 | 现行流程 / 系统截图或操作手册 | 图片 / PDF | 现状流程图的原始依据（CargoWare、共享盘费率表） | ⬜ 待放入原件 |
| M-04 | 样例单据（账单 / 合同费率页 / 差异台账） | PDF / Excel | 证据台账 E-001/E-005/E-010 的原始样本 | ⬜ 待放入原件 |

## 放置规则

- 文件名前缀与上表编号一致，例如 `M-01_项目任务书.pdf`；
- **原件不外传、不改写**：如涉客户价格，仅放脱敏版（价格数值可涂黑）；
- 若某份资料缺失，写一个同名的 `M-0X_缺失说明.md` 说明原因，不要用编造内容占位。

## 为什么单独成目录

FDE 流程要求「证据可回溯」：报告里的每个数字都要能指回一份原始资料。把原件单独放在 ④，任何评审人都能自己核对，不必信任报告里的转述。
