# src/ —— 代码区

**当前状态**：仅 `settlement/models.py`（数据契约雏形），无业务逻辑。

## 为什么 Stage 02 就放代码

白板上 `src/ → 代码` 是仓库必备结构，但 FDE 流程规定**代码在 Stage 05 构建集成时才写**。两者不冲突的做法：本阶段只固化**数据契约**（字段、枚举、追溯链），让 Stage 03 的需求评审有可讨论的字段依据，而不是拿 PPT 空谈。

## 约束

- 内网部署，不得调用外部模型传输价格字段（RL-1）；
- 不回写 CargoWare（只读 API，写入需 18 万定制）；
- 不存合同原文，只存"条款号 + 是否含该费用项 + 有效期"；
- 所有金额用 `Decimal`，禁止 `float` 参与金额计算。
